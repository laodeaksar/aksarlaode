Kamu adalah security engineer dan principal backend engineer ahli auth, RBAC, dan TypeScript.

Lakukan analisis mendalam pada folder "apps/auth-service". Fokus ke keamanan, skalabilitas, dan maintainability.

1. **Arsitektur & Data Flow**:
   - Trace flow lengkap: register → email verify → login → refresh → logout → delete account
   - Mapping semua endpoint, middleware, dan guard
   - Cek state management: stateless JWT vs stateful session, plus trade-offnya

2. **Security Deep Dive**:
   - Password: algoritma hashing, cost factor, pepper, migration path
   - JWT: algorithm, key rotation, expiry, claims, token binding, replay attack
   - Refresh Token: storage, rotation, reuse detection, revocation mechanism
   - Rate Limiting & Brute Force: per-IP, per-user, sliding window, CAPTCHA trigger
   - Input Validation: zod/class-validator, sanitization, mass assignment
   - CSRF, CORS, CSP, Secure Cookies: cek header dan config
   - Secret Management: .env, KMS, rotation, jangan sampai hardcode atau ke-log

3. **Authorization & RBAC**:
   - Model role/permission sekarang: role-based, attribute-based, atau ACL
   - Cek IDOR, horizontal/vertical privilege escalation
   - Cek hierarchy dan inheritance role
   - Review permission check di semua endpoint sensitive

4. **Database & Konsistensi**:
   - Skema users, sessions, tokens, password_resets: index, constraint, cascade
   - Transaction safety untuk operasi critical: register + create org, password reset
   - Cek race condition pada concurrent login dan password change
   - Audit log: aksi critical terekam lengkap atau tidak

5. **Integrasi & Eksternal**:
   - OAuth2/OIDC: state/nonce validation, PKCE, token exchange
   - Email provider: template injection, bounce handling, deliverability
   - Webhook: signature verification, retry, idempotency

6. **Reliability & Observability**:
   - Error handling: jangan bocorin stack trace atau info internal
   - Logging: struktur, PII masking, correlation ID
   - Metrics: login success/fail rate, latency, error rate
   - Test coverage: unit, integration, contract test untuk flow auth

7. **Performance**:
   - Cek N+1 query, missing index, DB lock
   - Cek cold start dan bundle size kalau pakai serverless
   - Cek token size dan payload JWT

Output format:
- **Executive Summary**: 3 kalimat kondisi service sekarang
- **Risk Matrix**: Tabel temuan dengan kolom Risk, Impact, Effort, Status
- **Bukti Kode**: Quote max 10 baris untuk tiap temuan kritis
- **Attack Scenario**: Jelaskan cara exploit tiap vulnerability
- **Fix & Kode Contoh**: Kode patch yang bisa langsung dipakai
- **Migration Plan**: Urutan perbaikan P0 → P1 → P2 tanpa downtime

Fokus ke hal yang bisa bikin akun diambil alih, data bocor, atau service down. Jangan buang waktu bahas style/linting.
